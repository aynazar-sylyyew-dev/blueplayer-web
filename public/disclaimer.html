1. About Blue Player

Blue Player is an offline-first Android music player. It plays audio files available in the device's local media library. It is not a music-streaming service, music catalogue, or media-hosting platform.

The app reads audio-library information through Android MediaStore after the required Android permissions have been granted. Depending on the features used, this can include track title, artist, album, duration, file location, and embedded artwork.

Blue Player includes local-library features such as playlists, favorites, bookmarks, playback-queue restoration, and audio-tag editing. Actions that change or remove local files or tags are performed on the device and are subject to Android permissions and the user's actions.

The app does not provide the audio files in the user's library. The online artwork features described below search for artwork using track or artist information; they do not upload the audio track itself as part of those lookups.

2. Embedded Artwork and Third-Party Services

Blue Player can display artwork already embedded in a local audio file. It can also search external services for album covers and artist images when Internet Access is enabled in the app's settings and the current network settings allow the request.

The current source code uses the following services:

  • Apple iTunes Search API — searches track information and album artwork.
  • Deezer API — searches for album covers and artist images.
  • MusicBrainz Web Service — searches release information used to locate album artwork.
  • Cover Art Archive — retrieves cover artwork associated with MusicBrainz releases.
  • Last.fm API — looks up track and album information, including available artwork.
  • Wikipedia API — searches English- and Russian-language Wikipedia pages for artist thumbnails.

For these lookups, the app sends search terms derived from the track title and artist name, or the artist name for artist-image searches. The relevant third-party service may also receive ordinary connection information, such as the device's IP address and request headers.

When an image is found, Blue Player downloads it and keeps a local copy in the app's private storage. Saved artwork can therefore remain available without another network request. Clearing the relevant artwork cache removes the app's cached copies and associated lookup records according to the app's cache controls.

Internet access is disabled by default in the app settings. Third-party services are independent services; their availability, terms, privacy practices, and content-licensing conditions are controlled by their respective operators.
